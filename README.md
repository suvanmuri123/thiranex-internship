# Netflix Data Cleaning & Visualization

## Project Overview
This project focuses on cleaning, preprocessing, and visualizing the Netflix Titles dataset using Python.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Data Cleaning Tasks
- Handled missing values
- Removed duplicates
- Processed date columns
- Checked for outliers

## Visualizations
- Movies vs TV Shows
- Top Countries
- Ratings Distribution
- Netflix Growth Over Time
- Genre Analysis

## Key Findings
- Movies dominate Netflix content.
- The USA contributes the most titles.
- Netflix experienced significant growth after 2015.
- TV-MA is a common rating category.

## Skills Demonstrated
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Visualization
- Data Storytelling
